# Fita 78 — Brechó Vintage

Site front-end completo, responsivo e sem framework.

## Como usar
1. Extraia o ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie os três arquivos (`index.html`, `style.css`, `script.js`) para sua hospedagem.

## Para personalizar
- Produtos: edite o array `products` em `script.js`.
- WhatsApp: troque `5511999999999` pelo número comercial com código do país.
- Cores, fontes e layout: `style.css`.
- Textos, seções e SEO: `index.html`.

## Observação
O checkout atual monta o pedido e abre o WhatsApp. Pagamento online, login, banco de dados e painel administrativo ainda precisam de um backend/API.
